# Документация лора

Здесь ведётся **канон** мистифицированной русской истории для игры (прототип — стартовая площадка, не клон Disciples).

## Как правим лор

1. Новое решение → запись в [`CHANGELOG.md`](./CHANGELOG.md) с датой.
2. Перенос в [`CANON.md`](./CANON.md) и нужный файл фракции.
3. Старые тезисы не удаляем молча: помечаем отмену в CHANGELOG.

## Содержание

- [`CANON.md`](./CANON.md) — свод канона
- [`CHANGELOG.md`](./CHANGELOG.md) — журнал фиксаций
- [`eschatology.md`](./eschatology.md) — Пришествие, Завет, отсрочка, 1991
- [`eras.md`](./eras.md) — Часть I, ВОВ-мост, Часть II
- [`factions/`](./factions/) — лор по фракциям
- [`refs/`](./refs/) — визуальные референсы
