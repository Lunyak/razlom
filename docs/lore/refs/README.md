# Визуальные референсы

Файлы `ref-01.png` … `ref-18.png` — пакет тона (в основном РИ / Память / казачий мрак).

`ri-uniform-field-1914.png` — канон **одежды живых войск РИ**: оливковый полевой мундир 1914, золотые погоны, фуражка. Не британский scarlet / малиновый китель.

Использовать как moodboard для UI, портретов, знамён, юнитов Памяти. Не все образы = готовый ростер.

Ключевые мотивы, которые уже каноничны по смыслу:

- орёл + крест;
- Адамова глава / «чаю воскресения…»;
- Бакланов (живой портрет и мёртвый всадник);
- схима, церковь, набат;
- имперский флаг ч/ж/б;
- «ты смотришь в бездну…».
