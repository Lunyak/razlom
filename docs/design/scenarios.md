# Сценарии и сага

## Принцип

**Механика одна** на все части саги.  
Меняется **контент**: карты-миссии, фракции эпохи, тексты, цели.

Как в Disciples: **кампания = цепочка сценариев**, сценарий = **упорядоченные карты-миссии**.  
Прошёл цель на карте N → герои переносятся на карту N+1. Последняя карта → победа в сценарии.

Свободных порталов между картами **нет**.

## Цепочка миссий

Порядок в `ScenarioDef.maps` — порядок миссий.  
У каждой карты свой `win` (иначе берётся `scenario.win`):

| `win.type` | Условие |
|------------|---------|
| `capture_capital` | На карте нет столицы указанной фракции |
| `capture_city` | Город с id принадлежит игроку |
| `eliminate_enemies` | Нет живых врагов/нейтралов на карте |
| `survive_turns` | Глобальный ход ≥ N |

При переходе: живые армии игрока появляются в `map.entry` (или у города РИ).

## Редактор

Меню → **Редактор карт**.  
**+ Карта** / **N** — следующая миссия. **Цель миссии** / **Бриф / вход** — условия победы.

**Сюжет** / **P** — конструктор кадров. Сцена = триггер (старт карты, победа, ход N, захват города, клетка) + упорядоченные шаги:

| Шаг | Что делает |
|-----|------------|
| Титул | Заголовок и текст на пластине |
| Речь | Хроника без портрета |
| Реплика | Говорящий + портрет + рамка фракции |
| Камера | Панорама на клетку (клик по карте) |
| Весть | Строка в ленте сообщений |
| Дар | Золото / мана / люди |

**Превью** прогоняет выбранную сцену. Сценарии из редактора пишут `plot` в JSON.

## Герои, артефакты, фракции

- **Классы** (`H` на карте, только ур.1 без XP): Офицер / Иеромонах / Разведчик — разные заклинания, ОД, лидерство.
- **Артефакты**: слоты оружие / броня / знамя / реликвия; дроп с кладов, руин и боёв; сумка **I**.
- **Казачество / Горцы**: свои юниты, здания и повышения. На Западном фронте — Станица Донская (`c_stanitsa`) и Аул Кавказа (`c_aul`); захват сохраняет культуру найма. Сюжетные сцены: подход к клетке у станицы/аула и `city_captured` — см. `plot` в `part1_1914.ts`.
