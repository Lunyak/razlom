# Разлом

Браузерная пошаговая стратегия в духе Disciples: карта мира, города, тактический бой.

## Стек

- Phaser 3
- TypeScript
- Vite

## Запуск

```bash
npm install
npm run dev
```

http://localhost:5473

Спрайты и UI лежат локально в `public/assets/` и в git не входят.

## Управление

- Клик по клетке — ход отряда
- Клик по врагу в зоне хода — бой
- **E** — конец хода
- В бою — клик по вражескому юниту
